Кастомный ультралегкий клиент VK Video для телевизоров LG webOS с аппаратным ускорением 4K, 100% отсутствием рекламы, современным интерфейсом (10-Foot UI Showcase & Rails), авторизацией по QR-коду и полной поддержкой пульта LG Magic Remote.

---

## 🌟 Ключевые возможности

### 1. Флагманский 10-Foot UI (по стандартам современных Smart TV)
* **Hero Showcase Banner:** Верхний широкоформатный промо-баннер с динамическим постером, метаданными и кнопкой прямого воспроизведения главной премьеры.
* **Тематические горизонтальные полки (Rails):**
  * ⏱️ **Продолжить просмотр** — с точным индикатором прогресса на превью роликов.
  * ✨ **Для вас** — гибридный алгоритмический подбор (Hybrid Affinity Scoring) на базе ваших серверных подписок, страниц избранного и ленты.
  * 🔔 **Новое в подписках** — свежие выпуски от авторов и сообществ, за которыми вы следите, в строгом хронологическом порядке.
  * 🔥 **Популярные шоу и проекты** — большие премьеры ведущих создателей (Ида Галич «Есть вопросики», Антон Шастун «Контакты», «Вписка», Азамат Мусагалиев «Кстати», ЧБД и др.).
  * 🎬 **Кино, фильмы и сериалы** — художественные и документальные фильмы.
  * ⚡ **Технологии, авто и наука** — обзоры гаджетов, автотематика и научпоп.
  * 📈 **Тренды недели** — самое популярное в VK Видео прямо сейчас.
* **Бесшовная догрузка (Infinite Scrolling):** Автоматическая фоновая подгрузка новых рекомендаций без фризов и задержек.

### 2. Умная пространственная навигация (Spatial Navigation & Magic Remote)
* **Shelf Focus Memory:** При переходе стрелками D-Pad Вверх/Вниз между полками система запоминает активную карточку на каждой полке.
* **Плавный скролл и указка:** Полная совместимость с гироскопической указкой LG Magic Remote (Air Mouse) и колесом прокрутки.
* **Быстрый доступ к меню:** Нажатие Влево на первой карточке полки переводит фокус в боковое навигационное меню.
* **Высококонтрастный фокус:** Четкий белый контур с неоновым свечением и масштабированием `scale(1.06)`, оптимизированный для больших OLED-экранов с расстояния 3 метров.

### 3. Аппаратное 4K воспроизведение без рекламы
* **100% Ad-Free:** Никаких сторонних рекламных SDK (Mail.ru, VAST, VMAP). Чистый прямой видеопоток.
* **Video Hole Punching:** Интерфейс рендерится в 60 FPS (1080p), а VPU декодирует поток в нативном 4K UHD (3840×2160).
* **Автоматический выбор максимального качества:** Плеер автоматически выбирает наивысший доступный профиль HLS/DASH (4K 2160p -> 1440p -> 1080p).
* **Подавление Screensaver:** Автоматическая блокировка заставки LG webOS во время просмотра.

### 4. Авторизация VK ID (Device Flow)
* Быстрый вход по QR-коду со смартфона через `vk.com/activate`.
* Поддержка нескольких аккаунтов с изолированной историей и избранным.
* Возможность использования без авторизации (гостевой режим с рекомендациями).

## 📁 Структура проекта

* `src/appinfo.json` — конфигурация манифеста webOS с флагами `privilegedJail`, `allowCrossDomain`.
* `src/index.html` — разметка приложения.
* `src/css/style.css` — стили, адаптированные под темную тему OLED 1920×1080.
* `src/js/app.js` — контроллер каталогов, полок, контекстного меню и модальных окон.
* `src/js/api.js` — клиент API VK (потоки, гибридное ранжирование, QR-авторизация).
* `src/js/player.js` — плеер с авто-выбором 4K и ускоренной перемоткой.
* `src/js/navigation.js` — пространственная навигация D-Pad и Magic Remote с памятью фокуса полок.
* `pack_ipk.py` — кроссплатформенный Python-сборщик `.ipk` пакетов webOS.
* `tests/` — модульные тесты логики API, навигации, плеера и целостности сборки.
* `build/` — собранные релизные `.ipk` пакеты.

## 🚀 Установка на ТВ

### Способ 1: Через webOS Dev Manager (Рекомендуется)
1. Установите и запустите [webOS Dev Manager](https://github.com/webosbrew/dev-manager) на ПК.
2. Подключитесь к вашему телевизору по IP.
3. Нажмите кнопку **Install**, выберите файл `build/org.webosbrew.vkvideo.adfree_1.0.0_all.ipk`.

### Способ 2: Через Homebrew Channel на ТВ
1. Скопируйте файл `.ipk` на флешку или через локальный HTTP/FTP-сервер.
2. Откройте **Homebrew Channel** на телевизоре и выберите установку из локального файла.

### Способ 3: Через SSH / Telnet CLI
Скопируйте `org.webosbrew.vkvideo.adfree_1.0.0_all.ipk` в `/tmp/` на ТВ и выполните:
```bash
luna-send -i -f luna://com.webos.appInstallService/install '{"id":"org.webosbrew.vkvideo.adfree","ipkUrl":"/tmp/org.webosbrew.vkvideo.adfree_1.0.0_all.ipk","subscribe":true}'
```
